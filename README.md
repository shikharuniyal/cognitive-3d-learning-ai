# Cognitive 3D Learning — AI-powered 3D Cognitive Trainer

Cognitive 3D Learning is an AI-powered single-player memory and spatial-reasoning game built with Three.js and Node.js. On-demand learning modules are procedurally generated by an LLM and rendered as interactive 3D scenes.



---

## Short pitch
**Cognitive 3D Learning** combines fast-paced memory challenges (pattern recall, sequence memory, spatial puzzles) with an AI-driven *Learning Mode* that generates lightweight, interactive 3D lessons on topics like DNA, the Solar System, and basic physics. It’s designed for rapid prototyping, portfolio demos, and research-focused EdTech exploration.

---

## Key features
- Adaptive gameplay: dynamic difficulty scaling, streak-based scoring, and cognitive analytics.
- AI Learning Mode: on-demand generation of validated Three.js modules for interactive lessons.
- Exportable analytics: per-session metrics (reaction time, accuracy trends) for research or demo dashboards.

---

## Tech stack
- Frontend: Three.js, HTML5, CSS, Webpack / Vite (or the included bundler).
- Backend: Node.js + Express (To orchestrates LLM prompting & generation ).
- LLM: uses :for content generation 
- Storage: local cache (simple file cache to avoid repeated LLM calls).
